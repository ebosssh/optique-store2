# OptikaZir

Інтернет-магазин оптики на Next.js: вітрина з каталогом товарів (оправи, сонцезахисні окуляри, лінзи, аксесуари, засоби догляду), кошик, оформлення замовлення та адмінка для керування товарами й замовленнями.

## Стек

- Next.js 16 (App Router) + React 19
- Prisma + PostgreSQL
- Tailwind CSS + shadcn/ui
- Zustand для кошика (зберігається в localStorage)

## Локальний запуск

Потрібен Node.js версії з `.nvmrc` (20.9.0 або новіше):

```bash
nvm use
```

Встановити залежності:

```bash
npm install
```

Скопіювати `.env.example` у `.env` і заповнити:

- `DATABASE_URL`: рядок підключення до PostgreSQL. Для розробки підійде безкоштовна база на Neon або Supabase.
- `ADMIN_PASSWORD`: пароль для входу в адмінку.
- `ADMIN_SESSION_SECRET`: довгий випадковий рядок для підпису сесій, наприклад результат `openssl rand -hex 32`.

Застосувати міграції та заповнити базу тестовими товарами:

```bash
npx prisma migrate dev
npx prisma db seed
```

Запустити сервер розробки:

```bash
npm run dev
```

Сайт відкриється на http://localhost:3000.

## Тести

```bash
npm test
```

Юніт-тести на Vitest покривають підпис і перевірку admin-сесій, обмеження на кількість спроб входу та форматування цін.

## Адмінка

Доступна за адресою `/admin/login`. Пароль береться зі змінної `ADMIN_PASSWORD`. Після входу можна додавати й редагувати товари, переглядати замовлення та змінювати їх статус.

## Сповіщення в Telegram

Необов'язково: якщо задати `TELEGRAM_BOT_TOKEN` і `TELEGRAM_CHAT_ID`, при кожному новому замовленні на сайті в Telegram прийде повідомлення з даними клієнта та списком товарів. Без цих змінних сайт працює як і раніше, просто без сповіщень.

Як налаштувати:

1. У Telegram напишіть **@BotFather**, команда `/newbot`, дайте боту ім'я. У відповідь прийде токен — це `TELEGRAM_BOT_TOKEN`.
2. Напишіть своєму новому боту будь-яке повідомлення (наприклад "привіт"), щоб він побачив ваш чат.
3. Дізнайтесь свій `chat_id`: відкрийте в браузері `https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates` і знайдіть у відповіді `"chat":{"id": ...}` — це число і є `TELEGRAM_CHAT_ID`.
4. Додайте обидва значення в `.env` (локально) і в налаштування Environment Variables на Vercel (для продакшену), після чого зробіть Redeploy.

## Автопідбір міста й відділення (Нова пошта)

Необов'язково: якщо задати `NOVA_POSHTA_API_KEY`, поля "Місто" й "Відділення" при оформленні замовлення стають пошуком із підказками замість вільного тексту. Без ключа показуються звичайні текстові поля, checkout працює як і раніше.

Як отримати ключ:

1. Зареєструйтесь / увійдіть на **new.novaposhta.ua**.
2. У кабінеті: Налаштування → Інтеграція → API ключі → створити ключ.
3. Додайте `NOVA_POSHTA_API_KEY` в `.env` (локально) і в Environment Variables на Vercel, після чого зробіть Redeploy.

## Деплой

Проєкт розрахований на Vercel. Змінні `DATABASE_URL`, `ADMIN_PASSWORD` і `ADMIN_SESSION_SECRET` потрібно виставити окремо в налаштуваннях проєкту на Vercel, оскільки файл `.env` у git не потрапляє. Міграції на продакшн-базі застосовуються автоматично при кожному білді (`npm run build` вже включає `prisma migrate deploy`), вручну нічого прогоняти не треба.
