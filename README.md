# OptikaZir

Інтернет-магазин оптики на Next.js: вітрина з каталогом товарів (оправи, сонцезахисні окуляри, лінзи, аксесуари, засоби догляду), кошик, оформлення замовлення та адмінка для керування товарами й замовленнями.

## Стек

- Next.js 16 (App Router) + React 19
- Prisma + PostgreSQL
- Tailwind CSS + shadcn/ui
- Zustand для кошика (зберігається в localStorage)

## Локальний запуск

Потрібен Node.js версії з `.nvmrc` (20.9.0 або новіше):

```bash
nvm use
```

Встановити залежності:

```bash
npm install
```

Скопіювати `.env.example` у `.env` і заповнити:

- `DATABASE_URL`: рядок підключення до PostgreSQL. Для розробки підійде безкоштовна база на Neon або Supabase.
- `ADMIN_PASSWORD`: пароль для входу в адмінку.
- `ADMIN_SESSION_SECRET`: довгий випадковий рядок для підпису сесій, наприклад результат `openssl rand -hex 32`.

Застосувати міграції та заповнити базу тестовими товарами:

```bash
npx prisma migrate dev
npx prisma db seed
```

Запустити сервер розробки:

```bash
npm run dev
```

Сайт відкриється на http://localhost:3000.

## Адмінка

Доступна за адресою `/admin/login`. Пароль береться зі змінної `ADMIN_PASSWORD`. Після входу можна додавати й редагувати товари, переглядати замовлення та змінювати їх статус.

## Деплой

Проєкт розрахований на Vercel. Змінні `DATABASE_URL`, `ADMIN_PASSWORD` і `ADMIN_SESSION_SECRET` потрібно виставити окремо в налаштуваннях проєкту на Vercel, оскільки файл `.env` у git не потрапляє. Після першого деплою міграції на продакшн-базі застосовуються командою:

```bash
npx prisma migrate deploy
```
